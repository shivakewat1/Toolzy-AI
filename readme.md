# 🚀 Toolzy AI

Toolzy AI is an **AI-powered SaaS platform** that provides a collection of smart tools for content creation, productivity, and image editing. It helps creators, developers, students, and professionals complete tasks faster using artificial intelligence.

---

## 🌟 Features

### ✍️ AI Content Tools
- **AI Article Writer** – Generate full-length articles from a topic or keyword.
- **Blog Title Generator** – Create engaging and SEO-friendly blog titles instantly.

### 🖼 AI Image Tools
- **AI Image Generator** – Generate images from text prompts.
- **Background Remover** – Automatically remove image backgrounds.
- **Object Remover** – Remove unwanted objects from images.

### 📄 Resume Tools
- **Resume Review AI**
  - Grammar suggestions
  - Skill improvement tips
  - Resume optimization feedback

---

## 📊 Dashboard

The platform includes a modern dashboard where users can:

- Access all AI tools
- View generated content history
- Track usage
- Manage account settings
